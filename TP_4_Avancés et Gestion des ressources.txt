# Gestion d'une flotte d'ordinateurs

L'atelier de réparation et de vente d'ordinateurs a grandi.

Les premiers développements ont permis :

la gestion des ordinateurs ; la gestion du stock ; l'utilisation d'EF Core ;
la création d'API Web ; les requêtes LINQ ; les traitements asynchrones.

L'équipe de développement souhaite maintenant améliorer la qualité du modèle métier en utilisant plusieurs fonctionnalités avancées du langage C# :

struct ; record ; indexeurs ; déconstruction ;
gestion des ressources ; IAsyncDisposable ; Garbage Collector.

L'objectif est également de conserver la compatibilité avec EF Core.


# Objectifs pédagogiques

À la fin de ce TP, vous serez capable de :

- Utiliser une structure (struct)
- Créer et utiliser un record
- Déconstruire un record
- Créer un indexeur personnalisé
- Manipuler des fichiers
- Comprendre le rôle du Garbage Collector
- Écrire des tests unitaires
- Adapter un modèle EF Core existant
- Adapter les tests unitaires
