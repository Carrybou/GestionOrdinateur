# Gestion d'une flotte d'ordinateurs

L'atelier informatique continue son évolution.
Les clients déposent leurs ordinateurs pour réparation et achètent du matériel.

# Objectifs pédagogiques

Vous devez améliorer votre API afin de :

- Exploiter les données avec LINQ
- Corriger les tests unitaires cassés par EF Core
- Simuler plusieurs réparations simultanées
- Sécuriser les accès concurrents aux stocks de pièces

## Réparation des tests unitaires (4 pts)

Depuis l'ajout de EFCore, nos tests unitaires ne fonctionne plus. Que faire ?

1. Aller dans notre projet GestionOrinateurs.Tests et s'assurer qu'il est bien ajouter à la solution.

2. Ajouter les package `Microsoft.EntityFrameworkCore.InMemory` et `FluentAssertions`

3. Ajouter une méthode qui permet de créer un contexte
`
private ParcInformatiqueContext CreerContexte()
{
    var options =
        new DbContextOptionsBuilder<ParcInformatiqueContext>()
            .UseInMemoryDatabase(Guid.NewGuid().ToString())
            .Options;

    return new ParcInformatiqueContext(options); // Contructeur à créer dans la classe ParcInformatiqueContext (DbContextOptions <ParcInformatiqueContext> options) : base (options)
}
`

4. Modifier les tests pour utiliser le context.
